# 元素和文本

用户界面通过将文本和 UI 元素组合在一起，以有用且美观的树状结构构建而成。一个展示文本和元素的 RSX 示例可能如下所示：

```rust
let author = "Dioxus Labs";
let content = "Build cool things ✌️";

rsx! {
    h1 { "Welcome to Dioxus!" }
    h3 { "Brought to you by {author}" }
    p { class: "main-content", {content} }
}
```

## 文本节点

在 RSX 中，任何用引号包裹的内容都会渲染为文本节点：

```rust
rsx! { "Hello world" }
```

Dioxus 中的文本节点自动实现与 Rust 的 [`format!`](https://doc.rust-lang.org/std/macro.format.html) 宏相同的规则，包括 [`Display`](https://doc.rust-lang.org/std/fmt/trait.Display.html) 和 [`Debug`](https://doc.rust-lang.org/std/fmt/trait.Debug.html) 打印。

```rust
let world = "earth";
rsx! { "Hello {world}!" }
```

与 Rust 的 format 宏不同，`rsx!` 允许我们嵌入完整的 Rust 表达式，这在处理复杂对象或内联调用函数时非常方便。

```rust
let user = use_signal(|| User {
    name: "Dioxus".to_string(),
});
rsx! { "Hello {user.read().name}" }
```

## 元素

HTML 的最基本构建块是元素。在 RSX 中，元素使用名称和花括号来声明。最常见的元素之一是 `input` 元素。input 元素创建一个交互式输入框：

```rust
rsx! {
    input {}
}
```

元素可以接受称为属性的额外参数，用于修改元素的渲染方式。属性以内联方式添加，类似于向结构体实例化添加字段：

```rust
rsx! {
    input { placeholder: "type something cool!" }
}
```

有大量的 HTML 元素可用，包括但不限于：
- 文本和内容：`p`、`h1`、`span`、`div`、`a`、`pre` 等
- 表单和输入：`form`、`input`、`textarea`、`select`、`button` 等
- 媒体内容：`img`、`video`、`audio`、`source`、`canvas`、`svg`、`iframe` 等
- 表格：`table`、`thead`、`tbody`、`tfoot`、`tr`、`th`、`td` 等
- 语义元素：`details`、`summary`、`dialog`、`progress`、`meter`、`time` 等

查看 [HTML 元素参考](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements) 获取完整列表。

## Element 类型

`rsx!` 宏返回一个 `Element` 类型的对象。这些对象可以赋值给变量、廉价克隆和存储在状态中。

```rust
let header: Element = rsx! {
    div {
        h1 { "Dioxus!" }
    }
};
```

我们甚至可以创建返回 `Element` 的函数：

```rust
fn create_description(content: &str) -> Element {
    rsx! {
        span { class: "description", "{content}" }
    }
}
```

在底层，`Element` 类型实际上是 `Result<VNode>` 的别名。在 Rust 中，[Result](https://doc.rust-lang.org/std/result/) 是一个枚举值，可以是 `Ok(value)` 或 `Err(error)`。这意味着我们可以对 Element 进行匹配，甚至在渲染时抛出错误：

```rust
fn create_description(content: &str) -> Element {
    if content.is_empty() {
        return Err("Missing description".into());
    }

    rsx! {
        span { class: "description", "{content}" }
    }
}
```

Dioxus 基于 [anyhow](https://docs.rs/anyhow/latest/anyhow/) 错误定义了自己的错误，然后与其他工具如错误边界和服务器函数组合使用。
