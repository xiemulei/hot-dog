# 构建用户界面

欢迎来到 Dioxus！本章将向您介绍如何用 Rust 和 Dioxus 构建精美的用户界面。

Dioxus 允许您使用 HTML 和 CSS 编写用户界面。在 Web 端，您的 UI 是原生且易于访问的；而在桌面和移动设备上，您的组件则会以 WebView 形式呈现，或通过混合原生组件以原生方式渲染。

HTML 和 CSS 让您能够打造极为精美、丰富且交互性强的用户体验。全球顶尖公司都在其网站和应用中广泛使用 HTML 和 CSS。甚至包括这个文档站点，也是用 HTML 和 CSS 构建的：

## Dioxus 为您提供的功能

Dioxus 为您提供了充分发挥 HTML、CSS 和 Rust 潜能的所有工具。

这些工具包括：
- Rust 代码、UI、样式和资源的热重载功能
- 适用于 Web、桌面和移动设备的跨平台渲染器
- 用于管理与更新状态的响应式系统
- 不断扩充的跨平台 API SDK
- 用于构建全栈 Web 应用的后端集成
- 打包与部署至生产环境的工具

借助 Dioxus，您可以实现任何仅使用 HTML 和 CSS 就能完成的事情。

## HTML 和 CSS 为您提供的优势

HTML 和 CSS 是强大的技术（尽管也存在不少局限性），它们让构建能在数十亿设备上正常运行的精美 UI 变得轻而易举。

HTML 和 CSS 为您提供丰富的工具：
- 多种布局算法（Flexbox、Grid、Table、Float、Block 等）
- 应用级主题化的样式表
- 每个元素的独立样式设置
- 出色的可访问性和屏幕阅读器支持
- 内联 SVG 支持
- CSS 动画
- 图片、视频和音频等多媒体元素
- 以及更多！

虽然 HTML 和 CSS 未必是做 UI 开发的最佳工具，但它们被广泛使用、几乎无处不在，并且拥有极其详尽的文档。

## Rust 为您带来的优势

为什么选择用 Rust 来编写 UI 框架？为什么用 Rust 开发应用？Rust 最初的设计目标是系统编程，不过我们 Dioxus 团队正致力于将其打造成适合高级编程如应用开发的语言。

Rust 的学习曲线确实较陡，但它的优势十分显著：
- 强大的标准化工具链（Cargo、rustc）
- 巨大的生态系统及优秀的包管理器（crates.io、Cargo.toml）
- 可在所有平台上运行——Mac、Windows、Linux、iOS、Android、Web 等
- 强类型的类型系统可在编译时避免许多逻辑错误
- 极佳的性能，媲美 C/C++ 等语言
- 即便在大规模场景下依然可靠

当然，Rust 也有一些不足之处，比如编译时间较长、学习曲线陡峭，以及一些语法上的小瑕疵。我们的目标是进一步提升"高级 Rust"的开发体验，使其能与 TypeScript 等语言相媲美，同时保留 Rust 本身的优势。
